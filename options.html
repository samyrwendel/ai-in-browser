Agente (modo Navegar)

Com o modo Navegar ligado no chat, o modelo pode ver a página, clicar, digitar, rolar, abrir abas, ler o código-fonte e tirar capturas de tela para concluir tarefas nas suas abas.

Usar DevTools Protocol (chrome.debugger)
Cliques e teclas “confiáveis”, captura de página inteira, console, rede e execução de JS sem bloqueio de CSP. O Chrome mostra uma barra “AI in Browser começou a depurar este navegador” enquanto o agente trabalha.
Permitir executar JavaScript na página
Ferramenta evaluate_js: o agente roda código na aba para extrair dados ou interagir. Desligue para um modo mais restrito.
Permitir histórico e downloads
Libera as ferramentas search_history e download. Opcional: a extensão só pede essas permissões quando você liga aqui.
Enviar capturas de tela ao modelo
Apenas para modelos com visão. Os elementos recebem etiquetas numeradas na imagem.

Por padrão o agente pergunta antes de ações sensíveis (compras, envio de mensagens, exclusões, senhas) e nunca resolve CAPTCHAs. Você pode interromper a qualquer momento com Parar ou Esc.

Sobre

AI in Browser é uma extensão de código aberto para Chrome, Brave, Edge e outros navegadores Chromium que conecta você aos melhores modelos de IA via OpenRouter, OpenAI, Anthropic, Ollama, LM Studio ou qualquer API compatível.

Atalhos
  • ⌘/Ctrl + ⇧ + Espaço abrir o painel
  • ⌘/Ctrl + K trocar modelo
  • ⌘/Ctrl + ⇧ + O nova conversa
  • Esc parar geração / fechar

Altere os atalhos em chrome://extensions/shortcuts.

Dicas
  • Clique com o botão direito em um texto selecionado → “Perguntar ao AI in Browser”.
  • Botão direito no ícone da extensão → “Abrir em uma aba” para a versão ampla.
  • Modelos com sufixo :free no OpenRouter não consomem créditos.
  • Ollama e LM Studio funcionam sem chave e sem configurar o servidor: a extensão ajusta o cabeçalho de origem nas próprias requisições. Só se ainda der 403, defina OLLAMA_ORIGINS="chrome-extension://*".
